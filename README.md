## 🎯 Purpose

Recipt V exists to solve **one real problem**:

> Schools still rely on manual fee tracking and handwritten receipts.

This project replaces that with a **simple, digital, and reliable system**.

No complexity.  
No bloated ERP.  
Just what’s needed.

---

## 🧠 Philosophy

- Keep it **simple**
- Keep it **fast**
- Keep it **useful**

Build small → Scale later.

---

## ✨ What It Does

- Track student fees  
- Show paid vs remaining  
- Generate instant receipts  
- Provide a clean admin view  
- Allow parents to check & pay
